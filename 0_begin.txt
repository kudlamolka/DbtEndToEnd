
********** Project Description **********

This Project is about learning to use DBT with Snowflake.

********** 25 July 2026 **********

Downloaded the data from the below URL 
https://grouplens.org/datasets/movielens/20m/
for this project.

Created a S3 bucket called 'dbt-e2e-kudla-molka', where I uploaded the csv files which I downloaded from the above URL.

It had 6 CSV Files:
"tags.csv"
"genome-scores.csv"
"genome-tags.csv"
"links.csv"
"movies.csv"
"ratings.csv" 

Then we created the Setup in snowflake

We first created a suitable role (TRANSFORM), which had all the permissions that of the ACCOUNTADMIN

Then a User was created named 'dbt'. 
This role was given default warehouse, database and role.

The proper permissions were also given accordingly. Refere the 00_Create_Database_Objects_and_Roles.sql

--------------------------------------------------------------------------------------------------------------

This will be followed by creation of Stage. 
For the stage, we will need the IAM User. So, first we created an IAM User on AWS.

This user was named 'snowflakenetflixuser'
and given AmazonS3FullAccess permission.

We created a new Access Key for this user.

This was added in CREDENTIALS part of the create Stage directly in Snowflake.

This is shown in the 01_S3_Stage_Connection.sql
